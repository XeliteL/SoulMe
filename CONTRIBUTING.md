# Contributing

SoulMe is currently maintained by a single developer and isn't actively
looking for outside code contributions.

- **Found a bug or have a suggestion?** Please open an [issue](../../issues) —
  bug reports and feature ideas are welcome.
- **Pull requests:** unsolicited PRs may not be reviewed. If you'd like to
  propose a change, open an issue first to discuss it.

## Development

```bash
npm install
npm run start   # dev server
npm run check   # format, lint, stylelint, tests
npm run fix     # auto-fix formatting/lint/stylelint
```

See [README.md](README.md) for the full stack and project structure.
